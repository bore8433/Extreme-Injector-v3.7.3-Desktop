## ❗️ Troubleshooting

| Problem                    | Solution                                      |
|----------------------------|-----------------------------------------------|
| Injection failed           | Run both injector and game as Administrator   |
| Process not showing        | Refresh process list or restart injector      |
| Antivirus blocks           | Add the folder to exclusions                  |
| DLL not injecting          | Try different injection method (Manual Map)   |
| Game crashes after inject  | Use compatible DLL or enable Stealth mode     |
